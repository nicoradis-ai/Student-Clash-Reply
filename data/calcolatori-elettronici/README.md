# Calcolatori Elettronici

- `slides/`: slide del corso, in PDF o markdown (in `.md` separa le slide con una riga `---`).
- `exams/`: temi d'esame vecchi. In `.md` ogni esercizio inizia con `## Esercizio N (X punti)`, così l'indice di copertura sa quanti punti vale. Anche i PDF vanno bene: ogni pagina diventa un blocco con 1 punto.

Facoltativo: una riga `Concetto: Nome` dentro una slide o un esercizio aiuta la modalità offline. Online i concetti li estrae l'LLM.
